# SaliX-Z

پوسته اندرویدی بهینه و اختصاصی برای **chat.z.ai** — بدون هیچ واسط، سرور یا API Key.

SaliX-Z وب‌سایت رسمی chat.z.ai را مستقیم در یک WebView بهینه‌شده اجرا می‌کند؛ یعنی همان تجربه‌ی رایگان مرورگر (GLM-5.3 ،GLM-5.3-Flash ،GLM-5.2 و بقیه) در یک پوسته بومی با هویت بصری [Sali-ZZ](https://github.com/SaliSalvia/Sali-ZZ) (تم بنفش تیره، اسپلش Z، رابط فارسی راست‌به‌چپ).

## امکانات

- اجرای مستقیم chat.z.ai — بدون proxy، بدون API Key، بدون محدودیت‌های API پولی
- ورود با حساب خودتان در وب‌سایت؛ نشست و کوکی‌ها بین اجراها حفظ می‌شود
- **سیستم پیش‌نمایش فایل موبایلی** برای هر خروجی مدل‌ها:
  - دکمه «پیش‌نمایش» روی هر بلوک کد داخل چت
  - نمایشگر کد با شماره خط، هایلایت سینتکس (js/ts/py/kotlin/java/json/xml/css/sql/bash/go/rust/...)، شکستن خطوط
  - تب «نتیجه» برای HTML/SVG (اجرا در sandbox امن) و رندر Markdown
  - نمایش تصویر با زوم
  - پنل دردری دو حالته (۶۲٪ / ۹۴٪ صفحه)، **جمع‌شدنی به یک pill شناور** تا چت ادامه یابد و با یک لمس برگردد
  - کپی / ذخیره در دانلودها / اشتراک‌گذاری / باز کردن با برنامه دیگر
- دریافت خودکار دانلودهای سایت (خروجی‌ها و فایل‌های ساخته‌شده) در همان پنل پیش‌نمایش
- منوی پوسته: بازآوری، حالت دسکتاپ/موبایل، تمام‌صفحه (immersive)، باز کردن در مرورگر، پاک کردن داده‌ها، درباره
- آپلود فایل از سایت (انتخاب‌گر فایل بومی)، ورودی صوتی سایت (با اجازه میکروفون)، ویدیوی تمام‌صفحه
- اشتراک متن از دیگر اپ‌ها به SaliX-Z (کپی خودکار برای پیست در چت)
- دکمه بازگشت هوشمند: پنل ← pill ← تاریخچه وب ← خروج (دو بار)

## نصب

APK را نصب کنید (اجازه «نصب از منابع ناشناس» لازم است). در اولین اجرا در صفحه ورود chat.z.ai با حساب خودتان وارد شوید؛ از آن به بعد نشست حفظ می‌شود.

> نکته ورود: اگر دکمه «ورود با گوگل» در WebView توسط گوگل مسدود شد، از **ورود با ایمیل/کد یک‌بارمصرف** استفاده کنید — پایدارتر است.

## بیلد

```bash
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

نیازمندی‌ها: JDK 17+، Android SDK 34. برای بیلد امضاشده release هم مثل Sali-ZZ می‌توانید از workflow موجود (`.github/workflows/build-apk.yml`) و سکرت‌های امضا استفاده کنید.

## ساختار

```
app/src/main/java/com/salixz/app/
  MainActivity.kt        شل WebView، منو، تمام‌صفحه، انتخاب فایل، دانلود
  PreviewController.kt   پنل پیش‌نمایش + pill + ذخیره/اشتراک + دسته‌بندی نوع فایل
  Bridge.kt              رابط JS→Native (SaliXBridge)
  Prefs.kt / App.kt
app/src/main/assets/
  shell.js    تزریق دکمه‌های «پیش‌نمایش/کپی» روی بلوک‌های کد سایت
  viewer.html نمایشگر کد/نتیجه/مارک‌داون/تصویر (بدون وابستگی خارجی)
```
